# Ассемблер и интерпретатор УВМ — Вариант №2 (Этап 1)

Консольное приложение на Python, реализующее первую стадию разработки учебной виртуальной машины (УВМ): **ассемблер**, который переводит текстовое представление команд в промежуточное представление (Intermediate Representation, IR).

## Требования варианта

Спецификация УВМ (Вариант №2) включает следующие команды (размер команды 5 байт):

1. **Загрузка константы** (A=1, биты 0–3; B=Константа, биты 4–35).
2. **Чтение значения из памяти** (A=12, биты 0–3; B=Смещение, биты 4–17).
3. **Запись значения в память** (A=0, биты 0–3).
4. **Бинарная операция: сложение** (A=9, биты 0–3).

## Спроектированный язык ассемблера

Для удобства человека выбран синтаксис в духе традиционных ассемблеров: `МНЕМОНИКА [аргумент]`. Комментарии начинаются с символа `;`.

| Мнемоника | Аргумент | Opcode (A) | Описание |
|-----------|----------|------------|----------|
| `LOAD`    | Число    | 1          | Загрузка константы на стек |
| `LOADM`   | Число    | 12         | Чтение из памяти по адресу (вершина стека) + смещение |
| `STORE`   | —        | 0          | Запись значения с вершины стека в память |
| `ADD`     | —        | 9          | Сложение двух элементов с вершины стека |

Пример программы на языке ассемблера:

```asm
; Тестовая программа из спецификации
LOAD 140     ; A=1, B=140
LOADM 866    ; A=12, B=866
STORE        ; A=0
ADD          ; A=9
